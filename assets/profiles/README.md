# Colour profiles

`FOGRA39.icc` — "FOGRA39L Coated" (ISO Coated v2 family), the CMYK output profile used for CMYK export.
The profile's own description reads: "This profile is free of known copyright restrictions". This text is taken from the file itself, not from a legal review.
Origin: supplied inside the PrintForge Preflight MVP (profiles/FOGRA39.icc); the original publisher/download page has not been verified. Before delivery, confirm the licence with the client's adviser, and ask the client to confirm FOGRA39 is the CMYK profile they want (the quotation says "one client-supplied licensed CMYK export profile").
The RGB working profile is sRGB (built in to libvips).
